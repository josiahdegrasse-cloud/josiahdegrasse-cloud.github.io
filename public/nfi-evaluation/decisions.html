RAG engineering decisions

Keep NFI's domain and governance

The product answers food-development questions using literature and canonical project evidence. Retrieval ranking does not replace review status, licensing, tenant scope, claim permissions or human approval. Existing schema and access contracts are preserved; this work requires no database migration.

Preserve hybrid ordering within governance tiers

The previous second sort included semantic distance and could undo reciprocal rank fusion. The new stable sort keeps approval, peer-review and evidence-type priority while preserving fused order within the same tier. A document now contributes at most one vote per retriever, regardless of its child-chunk count. This avoids rewarding long papers simply because they have more indexed chunks.

Preserve abstracts as evidence candidates

An abstract may state its aim and findings together. Explicitly labeled abstracts are no longer rejected simply for containing an introductory phrase. Bibliography and citation-density checks still apply. This does not mark a paper approved.

PostgreSQL full-text remains the production lexical backend

The offline pilot uses BM25 with exact cosine so it runs without production credentials. Production uses ts_rank_cd plus pgvector HNSW. No claim is made that these are identical. Replacing the production lexical index solely to match a portfolio checklist would introduce an unmeasured migration.

Make the cross-encoder optional

A pinned local ONNX cross-encoder avoids sending literature to another provider. Model and tokenizer hashes are checked before use, and model downloads are an explicit provisioning step. Enable with RAG_RERANKER_DIR only on a suitably provisioned host. It improves ordering in the small pilot, but increases latency and adds roughly another 90 MB model. It stays disabled by default, especially in the size-constrained Vercel deployment.

Resolve follow-ups without trusting generated history

The API accepts up to six previous user questions, each at most 1,500 characters. Referential follow-ups carry the last explicit user topic into retrieval. This is transparent deterministic expansion, not a claim of general conversational understanding. New standalone questions do not automatically inherit history. The response exposes retrieval_query; human feedback can identify wrong topic resolution before considering a more expensive LLM rewriter.

Separate retrieval tests from answer truth

Hit rate, MRR and nDCG test retrieval. They cannot establish faithfulness or a hallucination rate. Answer review binds named annotations to exact answer hashes; empty or stale reviews fail. The local-model judge is optional and compared with humans rather than treated as ground truth. The public pilot remains explicitly unreviewed until a domain expert supplies labels.

Require real citation markers after synthesis

Verified source sentences do not guarantee that generated prose remains factual. Synthesis without a citation or with an unknown source ID now falls back to the existing deterministic path. The code no longer assigns every prompt source to uncited prose. Valid citation IDs still do not prove entailment; answer review remains necessary.
